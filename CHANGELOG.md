# Changelog

## 0.1.1 — 2026-07-22

- Reworked both appearances around neutral white, black, and cool-gray Liquid Glass surfaces.
- Replaced the pervasive brown accent with restrained macOS blue interaction states.
- Fixed the Modern UI tab fade mismatch by aligning tab colors and using fit-sized tabs.
- Removed the terminal sticky-command divider and blended the scrollbar track into the terminal surface.
- Recolored the default folders from gold to a cool macOS-style blue.

## 0.1.0 — 2026-07-22

- Added adaptive Golden Gate light and dark color themes.
- Added a matching rounded product icon theme.
- Added a native-inspired file icon theme with light and dark variants.
- Added workspace settings for SF Mono, macOS window chrome, and automatic appearance switching.
